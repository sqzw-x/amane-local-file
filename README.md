# 本地文件播放插件

## 项目声明

本项目只接受缺陷报告, 不接受功能请求.

- 功能请求的 Issue 会被直接关闭.
- 不打算扩展功能集合, 并非完整的本地串流方案.
- 需要这些能力时请自行 fork, 或另外编写一个插件.

## 简介

本插件是播放源插件的示例实现, 用来播放媒体库中已索引的本地文件. 仅用来测试和展示插件系统功能, 定位是最小可用而非完整方案. 本地文件串流所需的复杂能力大多没有实现:

- 不实现解码、转码与封装转换. 交给浏览器的是文件本身的字节流, 能否播放取决于浏览器的解码能力, 例如 `.mkv` 通常无法在浏览器中直接播放.
- 不实现 HLS 切片与自适应码率.
- 不提取内嵌字幕与内嵌音轨, 只读取与媒体文件同目录、同名的外挂字幕文件.
- 不扫描本地文件: 直接使用数据库中已索引的媒体路径.
- 不解析 `.strm` 文件: 它只作为不可播的候选列出, 正文记录的地址不会被打开.
- 字幕只转换 `.vtt` 与 `.srt` 两种格式.

## 安装

从 Releases 下载 `sqzw.local.zip`, 在「管理 → 插件」页面上传

## 配置

| 字段 | 缺省 | 说明 |
|------|------|------|
| `sidecar_subtitles` | `true` | 查找同目录外挂字幕 |
| `sidecar_suffixes` | `[".vtt", ".srt"]` | 字幕扩展名白名单 |
